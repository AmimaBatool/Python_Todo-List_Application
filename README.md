Title: To-Do List Application

To-Do List Application is a simple command-line task management application developed by using Python. This program allows users to create a list of daily tasks by adding new tasks, viewing tasks, removing tasks and marking tasks as completed.
This project is about data management and teaches us to store multiple items in a single variable. This project helps to practice fundamental python concepts and build a practical beginner level application.

Features:
  1. Add a New Task.
  2. View all task with their status.
  3. Remove the task from the list.
  4. Mark a task as completed.
  5. Exit the Application.

Technologies Used:
  1. Python
  2. VS code

Python Concepts Used:
  1. List
  2. Dictionaries
  3. Functions
  4. Conditions
  5. Loops
  6. User input
  7. enumerate()
  7. Error Handling

How to Run:
  1. Download the project file.
  2. Open the project file in your VS code or any other editor. Make sure that python is installed in your computer.
  3. Open the terminal in project folder.
  4. Run this command "python todo.py" and press enter. Or simply run and debug the project.
  5. Program will run.
  6. Follow the menu shown on the terminal.
